#宇宙を理解するためのシミュレータ#
・地球の重力と衛星の遠心力とが釣り合って軌道を描くには、どのくらいのスピードを維持しなければいけないかを知ることができる。
・LEO（赤）、MEO（緑）、GEO（黄色）という領域毎に、どのような衛星があり、どのような役割をしているのか知ることができる。
・地球からの高度と赤道に対する傾斜角を下の２本のスライダーで調整できます。
・右のメルカトル地図の下にあるメニューから、実際にある衛星を選択することができます。
・衛星選択バーの下のバーからロケットを選択すると、ロケットの目的地が設定され、さらにその下のLAUNCHボタンで発射させることができます。
