【宇宙を理解するためのシミュレータ】

・衛星の地球からの高度や軌道角度をスライダーでぐりぐりいじってみよう！
・また、実際に存在する衛星やロケットを選んでみよう！ロケットは発射させて目的の衛星に飛ばすこともできるよ。

＊地球の重力と衛星の遠心力とが釣り合って軌道を描くには、どのくらいのスピードを維持しなければいけないかを知ることができます。
＊地球の自転は水色の点で、衛星の速度は地球に垂線を下した白い点で表現されており、静止軌道（GEO）までいくと地球の自転と衛星の回転速度が一致します。
＊また、LEO（赤）、MEO（緑）、GEO（黄色）という各領域に、どのような衛星があり、どのような役割をしているのか知ることができます（右のメルカトル地図の下にあるメニューから、実際にある衛星を選択することができます）。
＊さらに、衛星選択バーの下のバーからロケットを選択すると、ロケットの目的地が設定され、さらにその下のLAUNCHボタンで発射させることができます。
